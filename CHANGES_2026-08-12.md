### Fix 5: Enable zswap (Compressed Swap in RAM)
**Status:** Config created, **requires manual sudo + reboot** to activate

**Config created:** `/tmp/zswap.conf` (needs to be moved to `/etc/modprobe.d/zswap.conf`)

**Required commands (run manually):**
```bash
# Install config
sudo cp /tmp/zswap.conf /etc/modprobe.d/zswap.conf

# Enable now (without reboot)
echo 1 | sudo tee /sys/module/zswap/parameters/enabled

# Verify
cat /sys/module/zswap/parameters/enabled  # Should show "Y"

# Reboot to fully activate
sudo reboot
```

**zswap.conf content:**
```
options zswap enabled=1
options zswap compressor=zstd
options zswap max_pool_percent=20
options zswap accept_threshold_percent=90
```

**Expected impact:** Compresses swap pages in RAM before hitting disk, reduces swap I/O latency, effective RAM increase ~1-2 GiB under pressure.
